      Save a checkpoint

  git log --oneline -10
      Recent history

  git diff
      Unstaged code changes (text files)


Undo / restore
--------------

  git restore .
      Discard uncommitted changes to tracked files
      (or: git checkout -- .)

  git restore path/to/file
      Discard changes to one file only

  git reset --hard a50b4d8
      Hard reset to the baseline commit
      WARNING: destroys uncommitted work and commits after that point
      on this branch. Prefer a new branch for experiments.

  git switch -c experiment-name
      New branch for risky work (keep main clean)


Push to GitHub (optional)
-------------------------

  1. Create a new EMPTY private repo on GitHub (no README).

  2. Wire remote and push:

       git remote add origin https://github.com/YOUR_USER/TokiMenu.git
       # or SSH: git remote add origin git@github.com:YOUR_USER/TokiMenu.git

       git push -u origin main

  If GitHub CLI is installed and logged in:

       gh repo create TokiMenu --private --source=. --remote=origin --push


Open Toki Menus — Environment
-----------------------------

  The launcher dialog includes Environment:

    Local   — this Mac at http://127.0.0.1:8765 + toki_server.py
              Private Google Sheets work here (service account).

    Remote  — GitHub Pages static host (default
              https://absrdst.github.io/TokiMenu).
              A git push does NOT enable Pages by itself.
              Repo Settings → Pages → deploy from branch main (root).
              Private repos need GitHub Pro for Pages (or make public).
              Remote cannot run the Sheets API proxy by itself; use Local
              for live private menu data. (Dropbox/iCloud are not servers.)
              See docs/ARCHITECTURE.md — "Private Google Sheet + live boards".

  Also on the same panel:
    Single window — all boards preview (preview-all.html)
    Show extra info — board labels + zoom tips (default off)

  Portrait / square preview windows (height ≥ width) stack the four boards
  in one column — e.g. a 1440×2560 vertical monitor.


Toki Git Commit (app)
---------------------

  Double-click **Toki Git Commit.app** in the project folder (next to
  Open Toki Menus). Or from a terminal:

       python3 scripts/toki_git_commit.py
       python3 scripts/toki_git_commit.py -m "what you finished"

  It will, in one shot:

    1. Commit dirty files (asks for a message in a dialog)
    2. Pull the Google Sheet two ways and zip them together:
         • Menu.xlsx  — formatting (fills / fonts) via Drive export
         • values/*.csv — plain values via Sheets API
    3. Name the zip with the git commit SHA and push to origin

  Zip location + naming (always joinable to GitHub):

       backups/sheet-snapshots/Menu-sheet-<12-char-sha>.zip

  Example: commit 9ba31760fe6a… → Menu-sheet-9ba31760fe6a.zip
  Full 40-char SHA and GitHub URL are inside the zip (MANIFEST.txt).

  Log: /tmp/toki-git-commit.log

  Flags (advanced):

       --no-commit   --no-push   --no-sheet   --no-ui


Sheets are not in git
---------------------

  Google Sheet content lives in Drive, not in this repo.

  For a true full restore later:
    - Code: git checkout <sha>  (or GitHub commit page)
    - Sheet: unzip backups/sheet-snapshots/Menu-sheet-<same-sha-prefix>.zip
      (or Drive version history)

  Service account key stays only in secrets/ (never commit).


Dropbox + git
-------------

  Fine for solo use. Avoid editing the same files from two machines
  without committing first. Do not share one .git folder among multiple
  people via Dropbox.
