TokiMenu — handoff note (2026-08-09)
=====================================

WHAT CHANGED (code)
-------------------
1) Slideshow "plate object"
   - DOM: #hero-wrap > #hero-plate > (#hero img + #new-sticker)
   - Motion (opacity fade, Ken Burns --hero-zoom scale, .is-kb-in long transition)
     and drop-shadow live on #hero-plate, NOT on the raw img.
   - Children of the plate inherit all plate motion by default (sticker, future
     multi-size images for one menu item, etc.).
   - JS helpers: heroMotionEl(), hideHeroPlate(), applyPlateSticker(), setHeroZoom
     targets the plate.
   - updateHero drives plate show/hide + zoom; sticker is applied as decoration
     at show() time so it rides the plate fade/zoom (no separate scale sync).
   - Cache-bust: menu.css / menu.js ?v=20260809plate1 on index.html … index4.html

2) Family Portrait shadow cost
   - drop-shadow moved from each .family-portrait-item (img) to .family-portrait-slot
     (one filter per plate slot, not per bitmap). Wall path still filter:none.

3) Debug Menu → Full View
   - Sheet Debug Features column "Full View" (TRUE/FALSE), under master Debug Mode.
   - When enabled: #toki-debug-hud gets .hud-full-view — no max-height / no scroll
     on .hud-body (Fire Stick has no mouse).
   - Parsed via existing parseDebugMenu features map; isDebugFullView() helper.
   - Applied in updateDebugVisuals() when the HUD is shown.
