URL codes

Stick on a board URL. First ?, then &. Fire Stick / AbleSign: ?w=1920&dpr=1.

CodeWhat it does
dpr=1Honest 1× pixels. Stops AbleSign from loading 4K art on a 1080p stick.
w=1920Pretend the stage is 1920 CSS pixels wide (width too).
h=1080Pretend height is 1080 (height). Missing side is 16:9.
display=1920x1080Same as w + h.
pause=1Freeze motion (screenshots).
item=0Start on that menu row.
debug=1Dump debug table to the console.
preview=allWall preview path — not for TVs.

Full list including Manager QA codes: repo docs/URL_PARAMS.md.
